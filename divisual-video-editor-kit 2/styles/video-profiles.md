# Perfiles de Vídeo — Patrones de Animación por Tipo de Contenido

Cada tipo de vídeo tiene una estructura narrativa diferente que determina qué beats se esperan y en qué orden. Claude debe identificar el tipo de vídeo ANTES de planificar los beats.

---

## Cómo identificar el tipo de vídeo

Lee los primeros 15 segundos del transcript limpio y clasifica:

| Señal en el transcript | Tipo de vídeo |
|---|---|
| "hoy te voy a enseñar" / "paso a paso" / "tutorial" | TUTORIAL |
| "tengo que contarte algo" / "esto me pasó" / historia personal | STORYTELLING |
| "plazas limitadas" / "oferta" / "precio" / urgencia | VENTAS |
| "hoy hablamos con" / "mi invitado" / dos voces | PODCAST/ENTREVISTA |
| Pregunta retórica + problema de audiencia | EDUCATIVO |
| "nueva función" / "acaba de salir" / "han lanzado" | NOTICIA/NOVEDAD |
| Frase de impacto corta + pausa | MOTIVACIONAL |

---

## Perfil 1 — TUTORIAL

**Estructura narrativa:** Intro → Problema → Pasos numerados → Demo/Resultado → Resumen → CTA

**Secuencia de beats esperada:**
```
[0:00 - 0:08]  INTRO          → Título del tutorial (qué vas a aprender)
[cuando empieza el paso 1]  PASO 1  → Bullet list que se va completando
[cuando empieza el paso 2]  PASO 2  → Nuevo bullet o continuación de la lista
[...cada paso...]           PASO N  → Ídem
[si hay resultado/demo]     RESULTADO → Stat card con el resultado conseguido
[últimos 5s]               CIERRE  → "Ya sabes cómo hacer X"
```

**Reglas específicas del tutorial:**
- Los pasos se animan con bullet list escalonada — cada paso aparece cuando el hablante lo menciona
- Si hay una demo visual (pantalla compartida), NO añadir cards grandes que tapen la demo
- Si el hablante menciona un resultado final, siempre stat card
- El CTA va ligado al recurso del tutorial (descarga, link, etc.)

**Densidad de beats:** Media — no todos los pasos necesitan card. Solo los que el hablante enfatiza.

## Perfil 2 — VENTAS / PITCH

**Estructura narrativa:** Hook → Dolor → Agitación → Solución → Prueba → Urgencia → CTA

**Secuencia de beats esperada:**
```
[0:00 - 0:08]  HOOK           → Frase de impacto (highlight card, texto grande)
[dolor]        DOLOR          → Highlight del problema (texto, no número)
[agitación]    CONSECUENCIA   → Stat card si hay dato ("el 80% nunca llega a...")
[solución]     SOLUCIÓN       → Título de la solución (card limpia)
[prueba]       RESULTADO      → Stat card con resultado del cliente
[urgencia]     URGENCIA       → Urgency card (rojo, fecha, plazas)
[CTA]          CTA            → CTA card con el paso a dar
[cierre]       CIERRE         → Refuerzo del beneficio principal
```

**Reglas específicas de ventas:**
- Alta densidad de beats — casi cada segmento tiene animación
- Los números SIEMPRE con stat card — son la prueba social
- La urgencia SIEMPRE con color rojo o naranja
- El CTA es el beat más importante — debe ser el más visible del vídeo
- Nunca animar con colores fríos en un pitch de ventas (el azul resta urgencia)

**Densidad de beats:** Alta — prácticamente todos los segmentos tienen algún elemento visual.

## Perfil 3 — EDUCATIVO / FORMATIVO

**Estructura narrativa:** Contexto → Concepto → Explicación → Ejemplo → Aplicación → Resumen

**Secuencia de beats esperada:**
```
[0:00 - 0:08]  INTRO          → Título del tema (card limpia, tipografía grande)
[concepto]     DEFINICIÓN     → Highlight con la definición en texto grande
[datos]        CONTEXTO       → Stat card con datos de relevancia
[ejemplo]      EJEMPLO        → Card con el caso/ejemplo visualizado
[aplicación]   CÓMO APLICARLO → Bullet list con los pasos de aplicación
[cierre]       RESUMEN        → Bullet list con los 3 puntos clave del vídeo
```

**Reglas específicas del educativo:**
- Priorizar la claridad sobre el impacto visual
- Los conceptos clave siempre con highlight
- Los ejemplos con cards que muestren contexto (nombre, situación)
- El resumen final siempre — es lo que el espectador se lleva
- Densidad media-baja — dejar respirar el contenido

**Densidad de beats:** Baja-Media — los espacios sin animación son intencionales.

---

## Perfil 4 — STORYTELLING / HISTORIA PERSONAL

**Estructura narrativa:** Situación inicial → Conflicto → Punto de inflexión → Resolución → Lección

**Secuencia de beats esperada:**
```
[situación]    CONTEXTO       → Card con el tiempo/lugar/personaje si aplica
[conflicto]    PROBLEMA       → Highlight de la frase de conflicto
[dato clave]   STAT           → Si hay un número en la historia, stat card
[inflexión]    MOMENTO CLAVE  → Highlight grande — la frase más importante
[resolución]   RESULTADO      → Stat card con el resultado conseguido
[lección]      APRENDIZAJE    → Quote card con la lección principal
[cierre]       CIERRE         → Cierre visual limpio
```

**Reglas específicas del storytelling:**
- NO sobrecargar de beats — la historia debe fluir naturalmente
- El beat más importante es el MOMENTO CLAVE — debe ser el más impactante visualmente
- Las citas textuales con quote card (borde amarillo, texto en cursiva)
- Evitar stat cards genéricas si la historia es personal — el dato debe ser específico

**Densidad de beats:** Baja — el protagonista es la narrativa, no las animaciones.

---

## Perfil 5 — PODCAST / ENTREVISTA

**Estructura narrativa:** No lineal — ideas, preguntas, respuestas, anécdotas

**Secuencia de beats esperada:**
```
[inicio]       INTRO          → Nombre del invitado + tema del episodio
[dato clave]   STAT           → Cuando cualquiera menciona un número
[cita fuerte]  QUOTE          → La frase más memorable del invitado
[idea clave]   HIGHLIGHT      → Conceptos que el entrevistador enfatiza
[final]        CIERRE         → "Escucha el episodio completo" o tema del próximo
```

**Reglas específicas del podcast:**
- Si hay dos voces, no animar durante el cambio de turno
- Priorizar las frases del invitado sobre las del entrevistador
- Los nombres propios y datos verificables → stat card o highlight
- Los clips cortos (< 60s) solo llevan INTRO + 1-2 beats + CIERRE

**Densidad de beats:** Baja — uno cada 20-30 segundos máximo.

---

## Perfil 6 — NOTICIA / NOVEDAD

**Estructura narrativa:** Qué pasó → Por qué importa → Impacto → Qué hacer

**Secuencia de beats esperada:**
```
[0:00 - 0:08]  INTRO          → "NUEVO: [nombre del producto/evento]"
[qué es]       DATO CLAVE     → El dato más impactante de la novedad
[impacto]      COMPARATIVA    → Si hay comparativa (antes/después), two-column card
[oportunidad]  OPORTUNIDAD    → Cómo aprovechar esto (bullet list breve)
[cierre]       CTA            → Qué hacer ahora mismo
```

**Reglas específicas de noticias:**
- El INTRO debe comunicar inmediatamente QUÉ es la novedad
- Alta velocidad — los beats van rápido, la noticia no puede respirar demasiado
- Si hay números de impacto (downloads, usuarios, precio), SIEMPRE stat card
- El CTA es urgente por naturaleza — tratarlo como urgency card

**Densidad de beats:** Alta — el ritmo rápido requiere más estímulo visual.

---

## Perfil 7 — MOTIVACIONAL / INSPIRACIONAL

**Estructura narrativa:** Problema universal → Verdad incómoda → Reencuadre → Acción

**Secuencia de beats esperada:**
```
[0:00 - 0:08]  HOOK           → Frase de impacto (texto grande, sin card)
[verdad]       HIGHLIGHT      → La frase más poderosa del vídeo
[dato]         STAT           → Si hay estadística, stat card impactante
[reencuadre]   QUOTE          → La perspectiva alternativa en quote card
[acción]       BULLET         → Los pasos concretos (si los hay)
[cierre]       CIERRE         → Frase de cierre memorable
```

**Reglas específicas del motivacional:**
- Las frases de impacto sin card — solo texto flotante con text-shadow
- Nunca cards "corporativas" en vídeos motivacionales — rompen la energía
- Los colores deben ser cálidos (naranja, amarillo, rojo) — nunca azul corporativo
- El ritmo visual debe acompañar la emoción — beats rápidos en momentos de energía

**Densidad de beats:** Media — calidad sobre cantidad.

## Tabla resumen

| Perfil | Densidad | Color dominante | Beat más importante |
|---|---|---|---|
| Tutorial | Media | Azul / Verde | Bullet list de pasos |
| Ventas | Alta | Rojo / Naranja | CTA card |
| Educativo | Baja-Media | Azul | Highlight de concepto |
| Storytelling | Baja | Amarillo / Acento cliente | Momento clave |
| Podcast | Baja | Acento cliente | Quote card |
| Noticia | Alta | Acento cliente + Rojo | Stat card de impacto |
| Motivacional | Media | Naranja / Rojo | Frase de impacto flotante |

## Si el vídeo no encaja en ningún perfil

Usa este orden de prioridad para los beats:
1. INTRO (obligatorio)
2. Aplica triggers.md mecánicamente
3. CIERRE (obligatorio)
4. No fuerces beats donde no hay triggers claros
